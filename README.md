# 🎮 RPG ゲーム - ドット絵版

ドット絵を使ったダンジョン探索・パーティーコマンド戦闘のRPGです。

## Unity版

Unity 6向けプロジェクトを [UnityRPG](UnityRPG/README.md) に追加しました。Unity Hubでそのフォルダーを開き、Adventureシーンを再生してください。既存Python版も引き続き実行できます。移行範囲・操作・確認方法はUnity版READMEに記載しています。

更新したUnity版のWindowsゲームは `UnityRPG/Build/Windows/TowerAdventure.exe`。自由移動、仲間のコマンド戦闘、100階の物語、装備・店・道具、保存枠、難易度3段階に対応しています。難易度・検証結果は [Unity版のバランス説明](UnityRPG/BALANCE.md) を参照してください。以下は従来Python版の説明です。

## 📋 ゲーム概要

- **ジャンル**: ダンジョン探索型RPG
- **目標**: 100階層に到達してゲームクリア
- **特徴**:
  - ドット絵グラフィックス
  - レベルアップシステム
  - スキルシステム
  - 装備・インベントリシステム
  - ショップ機能
  - 敵スキル・状態異常システム

## ⌨️ 操作方法

| キー | 機能 |
|------|------|
| **WASD** | プレイヤー移動 |
| **I** | インベントリを開く/閉じる |
| **数字(0-9)** | アイテム装備 / ショップ購入 |
| **1 / 2 / 3 / 4** | 戦闘で攻撃 / 呪文選択 / 防御 / 逃走を予約 |
| **← / →、Q / E、Enter** | 戦闘で仲間選択 / 敵選択 / 予約した行動を実行 |
| **ESC** | メニューを閉じる / 呪文選択を戻る |

## 📊 ゲーム要素

### ステータス

- **HP**: 体力（0になるとゲームオーバー）
- **MP**: マジックポイント（スキル使用に消費）
- **ATK**: 攻撃力（武器や装飾品で上昇）
- **DEF**: 防御力（防具や装飾品で上昇）
- **EXP**: 経験値（敵を倒すと獲得、満タンでレベルアップ）

### スキルシステム

- **ファイア**: 攻撃スキル（MP10消費）
- **ヒール**: 回復スキル（MP8消費）
- レベルアップで新しいスキルが習得できます

### 装備システム

- **武器**: 攻撃力アップ
- **防具**: 防御力・最大HP アップ
- **装飾品**: 複合効果

### 敵スキル

敵も30%の確率でスキルを使用します：

- **パワーアタック**: 高威力攻撃
- **火炎放射**: 高ダメージ＋火傷状態
- **フロストボルト**: 攻撃＋凍結状態
- その他多数

### 状態異常

- **麻痺**: 行動ができない
- **毒**: 毎ターンダメージ
- **火傷**: 毎ターン高ダメージ
- **凍結**: 次のターンスキップ

## 💰 ゲーム進行

1. ワールドマップで敵を探す（灰色のタイル）
2. 敵と戦闘して経験値とアイテムを獲得
3. ショップ（ピンク色）でアイテムを購入
4. 装備を整える
5. レベルアップしてステータス上昇
6. 100階層まで敵を倒し続ける

## 🏆 ゲームクリア条件

**100階層に到達する**

- 敵を倒すたびに階層が1階上がります
- 100階層に到達するとクリア画面が表示されます
- 最終スコア（レベル × ゴールド）で成績が決まります

## 📝 データファイル

### enemies.json

敵の能力値とドロップ率を定義

```json
{
  "スライム": {
    "hp": 20,
    "attack": 5,
    "defense": 0,
    "exp": 10,
    "skill": "none",
    "color": [100, 255, 100],
    "desc": "最弱の敵"
  }
}
```

### equipment.json

武器、防具、装飾品を定義

```json
{
  "weapon": {
    "木の剣": {"attack": 2, "price": 0, "desc": "初期装備"},
    "鉄の剣": {"attack": 8, "price": 100, "desc": "基本的な剣"}
  }
}
```

### skills.json

スキルの効果とコストを定義

```json
{
  "ファイア": {"cost": 10, "power": 25, "unlock": 1},
  "ヒール": {"cost": 8, "heal": 30, "unlock": 1}
}
```

## 🐛 トラブルシューティング

**Q: ゲームが起動しない**
- Pygame がインストールされているか確認: `pip install pygame`
- データフォルダが存在するか確認

**Q: 画像が表示されない**
- assets フォルダが存在するか確認
- `python generate_assets.py` を実行してアセットを再生成

**Q: スクリーンショットを取りたい**
- Pygame は自動的にスクリーンをキャプチャ機能は未実装ですが、別ツールで撮影可能です
