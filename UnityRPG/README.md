# Unity版 — 星の塔

## 今回の磨き込み

- 章ごとの混成敵編成と、盾役が味方をかばう行動を追加。魔法で回復役を直接狙えます。
- 連携は使用後に1ターン準備が必要。全体攻撃の威力を調整し、威力・消費MP・再使用条件を表示します。
- Gキーと「全員防御」で一括予約。不要な満タン回復や、失敗した連携で行動が飛ばされる問題を修正しました。
- 51階から補給地点の工房で五人を永久強化できます。攻撃・守り・魔法／回復の3種類、各3段階。価格は1500／3500／6500Gです。
- 各章の3番目の階に探索装置を追加。無料で階段への経路を記録するか、金貨でその階の守りを上げるか選べます。必要金貨を明示し、不足時は購入できません。
- 章に応じて部屋の多さを変更。連携の準備、工房、装置の状態も保存し、旧Unityセーブは未強化として移行します。

更新後の実行版による100階クリアと画面確認は [PLAY_REVIEW.md](PLAY_REVIEW.md) に記録しています。

Unity 6.0 (6000.0.60f1) 用の、実際に探索・会話・パーティー戦闘を遊べる移行版です。

Windows版は `Build/Windows/TowerAdventure.exe` から起動できます。難易度は「標準」「物語重視」「手ごたえ」の3段階。Pで設定・一時停止、音量調整、演出の簡略化ができます。100階と結末までの確認範囲・難易度調整の数値は [BALANCE.md](BALANCE.md) に記載しています。

通常敵の固有行動、10章の背景と環境音、装備の特殊効果、会話履歴・文字速度、クリア後の成果記録を追加しました。実行版での100階踏破の結果と感想は [PLAY_REVIEW.md](PLAY_REVIEW.md) に記録します。

主人公と仲間4人に歩行アニメーションを追加しました。正面・横・後ろ向きの各2フレーム、左向きは横向きの反転で表示。実際に進んだ距離で足を切り替え、壁に押し付けるだけでは足踏みしません。仲間は歩いた軌跡を追い、曲がり角で壁を横切りません。ロード・階層移動・再挑戦では隊列を作り直します。仲間の軌跡は演出用で、セーブする主人公の座標やマップ判定を変更しません。

戦闘画面には味方5人の全身も表示し、攻撃時の踏み込み、魔法・回復時の動き、防御姿勢、被弾、倒れた姿を見せます。敵にも待機と攻撃の動きがあります。味方の全身をクリックして選択可能。探索の足音と足元の影、近くの調べられる物のE表示も追加しました。Pの演出簡略化で揺れ・光・待ち時間を抑えられます。歩行の向きとフレームは移動を示すため残します。

宝箱は金貨・道具の獲得表示と光の粒、階層移動・遭遇は短い暗転、通常戦の勝利は報酬・レベルアップの表示を追加。HP・MPバーはなめらかに追従します。回復時は仲間ごとの回復表示、魔法は炎・雷・毒の色と粒を表示。演出簡略化では短い結果表示を残し、暗転・粒・バーの補間を省きます。ボス勝利は専用会話を優先します。

戦闘中のR、または「前の行動を予約」で、前ターンの攻撃・防御・使用可能な魔法を予約できます。倒れた敵は生存中の敵へ切り替え、MP不足の魔法・戦闘不能の味方を対象にした回復・道具・連携参加者は未予約にします。必ず内容を確認してEnterで実行します。前ターンの履歴は同じ戦闘内だけで使え、ロード直後は次に実行したターンから利用できます。

## 起動

1. Unity Hub の「追加」でこの `UnityRPG` フォルダーを選びます。
2. `Assets/Scenes/Adventure.unity` を開き、Play を押します。
3. シーンがない場合はメニュー `Adventure > Create or open game scene` を実行します。

Windows実行ファイルは `Adventure > Build Windows game` で作成します。
追加のAsset Store素材や外部パッケージは不要です。

## 操作

- 探索: WASD または矢印を押し続けて自由移動。斜め移動にも対応。Shiftでダッシュ。画面の方向ボタンも押し続けて移動。
- 宝箱: 近くでE、または接触すると取得。扉: 接触またはEで開き、そのまま通過。
- 休憩・会話・階段: 近くでE。階段は意図せず進まないよう、Eを押した時だけ次の階へ。
- 戦闘: 仲間のカードで行動する仲間、敵のボタンで対象を選択。
- 攻撃・防御・魔法を全員に予約し「予約を実行」。左右キーで仲間、Q/Eで敵、1/2で攻撃/防御、Enterで実行。
- 回復: 先に「ヒールの対象」を選んでからヒールを予約。戦闘不能は休憩で復活。
- F5: 保存、F9: 再開、F11: 全画面。

## 移行した範囲

既存のドット絵・音楽・敵データ・魔法データ・冒頭の分岐会話を利用しています。
5人のパーティー、MP、魔法の毒・麻痺、レベルアップ、会話の6性格軸と主人公の初期タイプを実装しています。
100階まで進行し、10階ごとにテーマと敵種が変わります。10階ごとのボスは溜め→全体攻撃→隙の3ターン周期です。
補給は1階・3階ごと・5階ごと・各ボス直前の階に保証します。報酬は金貨・経験値・道具です。

**Python版の全機能との互換移植ではありません。** 仲間の離脱・既存の全イベント条件・RL敵AI・各種地形ギミックは未移植です。100階の個別の地形・報酬を作り込む段階は残っています。物語は10章と各階の探索会話を新規実装しています。
Python版の `save.json` とは形式が異なり、Unity版は新しい冒険から始めます。

## セーブ

`Application.persistentDataPath/adventure-v1.json` に保存します。Windowsでは通常 `%USERPROFILE%/AppData/LocalLow/Yuuki/Tower Adventure/` です。
各階の地形・開いた扉・取得した宝箱・探索済みマス・倒した敵・ボス・会話済みフラグ、パーティー、性格、会話ノード、連続した座標とエンカウントまでの移動距離、戦闘中の敵HP・状態・予約行動を保存します。
一時ファイルを書き込み、同期してから置換。前回の保存を `.bak` に残し、メインが壊れていればバックアップから復元します。ロード失敗時には現在の冒険を維持します。階段移動・休憩・会話終了・ボス突入前は専用の自動保存枠に保存します。手動枠を上書きしません。

## ランダムダンジョンと自由移動

- 各階の迷路と小さな部屋を生成し、実際に歩ける最長距離となる入口・階段の組を選びます。同じ距離の組はランダムに選択します。階段と入口が同じ場所になることはありません。
- 宝箱2～4個、扉、会話地点を空いている場所へランダム配置。すべての地点への通行を保証します。ボス前の補給は階段への道中に配置します。
- 通常の敵はマップに固定配置しません。歩いた距離に応じて遭遇し、敵の種類・数も階層に合わせて変化します。停止中・壁へ押し続けている間は距離を加算しません。
- 戦闘後・逃走後・補給後は、次の遭遇まで20～30相当の移動距離を確保します。逃走後もその場から探索を再開できます。
- プレイヤーの座標は連続した値です。斜め移動の速度を揃え、壁沿いのスライドと小刻みな衝突判定で壁抜けを防ぎます。描画の床にもマス目は付けません。
- 敵の気配、探索済みのミニマップ、近くの物に対するEの操作案内を表示します。
- 旧Unityセーブは位置を連続座標に移行し、保存済みの地形・宝箱・扉を保持します。ランダムな地形・入口・階段は、新しい冒険または未訪問の階から反映されます。

生成と保存の自動チェックに加え、Unityの実行ファイル上で経路を歩き、途中の端数座標を含む描画を確認しました。確認用の探索画面は `VisualChecks/07-free-movement.png` です。

## 物語と仲間の会話

世界から名前と記憶が消える原因を追い、星の塔を登ります。10階ごとのボス撃破後に章が進み、仲間の過去と塔の秘密がつながります。
各階の会話地点・休憩地点には、その階に合わせた探索会話があります。相手の口調と顔を表示し、選んだ言葉に対する返答も描きます。長い文章はスクロールできます。
探索装置を含め全415ノード、100階それぞれの探索会話、10章、3つの結末を用意しました。仲間への共感で結んだ約束はエピローグに反映されます。
会話途中のノード、会話後の戻り先、約束、既読状態も保存します。既存のUnityセーブから続けられ、現在階の未読の章は階段で補完します。
設定は [STORY.md](STORY.md)、会話データは `Assets/Resources/Data/story.json`、再生成用原稿は `generate_story.ps1` です。

## 仲間と探索の追加要素

- 仲間4人の専用イベント：12・22・42・52階以降で順に発生。記憶の灯りを調べるか、休憩地点で相談すると始まります。以前のセーブでも休憩地点から参加できます。イベント中の選択と返答から、仲間の約束と連携技につながります。
- 連携技：盾と矢、祈りの星灯り、森の一斉射、五人の灯り。戦闘の「連携技」で参加者、MP、効果を確認して予約します。残る仲間にも行動を予約してください。参加者に別の行動を予約すると連携を解除します。
- 状況会話：宝箱、負傷、戦闘勝利、ボス撃破、休憩、階層移動、救助に反応する短い会話。探索中の顔付き表示は9秒、発生間隔は18秒以上。操作を中断しません。
- 寄り道：記憶を解放してMP回復と周辺地図、旅人の救助で入口への道案内または有料回復、封印の宝箱で少し強い敵と戦い金貨・最大MPを獲得。逃走すると宝箱が戻り、再挑戦できます。
- 記録帳：Jまたは「記録」で目的、仲間のイベント・連携技、約束、章の振り返り、操作説明を確認。未読の章は表示しません。開いている間は移動・戦闘入力を停止します。JまたはEscで閉じます。
- 操作改善：全員の攻撃を一括予約し、実行前に個別に変更可能。ミニマップには記憶・封印の宝箱を追加し、地図上の小物にも名前を表示。

新しい要素の処理は `AdventureJourney.cs` にまとめています。会話データ390ノードに専用イベント・寄り道15ノードを加え、探索装置10ノードも加え、合計415ノードです。全イベントのフラグ、連携予約、宝箱の報酬戦闘をセーブします。新しい寄り道の配置は未訪問の階から反映します。

検証：専用イベント4件×2経路、会話途中の復帰、連携予約の保存とMP消費、無料救助、資金不足時の再選択、記憶の報酬、危険な宝箱からの逃走・再挑戦・戦闘途中復帰・報酬の一回性、記録帳の移動停止を自動確認。画面は `VisualChecks/08-journey-world.png` ～ `12-combo-reserved.png` で確認します。

## 装備・店・道具・セーブ枠

Bまたは「どうぐ」でアイテムと装備を開きます。薬草はHP65または最大HPの35%の大きい方＋毒解除、魔水はMP25または最大MPの30%の大きい方、蘇生の羽は最大HPの半分で復活。ヒールは基礎回復量に使用者の攻撃の半分と魔導具の効果を加えます。戦闘中は選択した仲間の行動として予約し、対象は戦闘不能の仲間も選べます。残りの所持数を超える予約はできません。効果がない対象には消費しません。
武器はLvごとに攻撃＋5、防具は守り＋3、魔導具は魔法威力＋6・回復＋8・消費MP−2（最低1）。所持品を仲間に装備し直しても重複せず、基礎能力を変更しません。装備変更は戦闘外で行います。
店は補給地点から「店・装備」で利用。装備Lv2は21階、Lv3は51階で入荷。道具は20/35/90G、装備は60/180/480Gです。宝箱から道具も出ます。以前のセーブには初期の道具と空の装備在庫を補います。
保存枠は手動3枠＋自動保存。階層・レベル・モード・日時・プレイ分数を表示。既存の `adventure-v1.json` はスロット1です。F5/F9は選択した手動枠に保存/復帰。既存の枠への保存は画面で上書き確認し、F5は直接保存します。全滅状態で以前の保存を上書きしません。

## テンポ・チュートリアル・演出・ボス

エンカウントまでの距離を20～30に変更。補給地点は1階・3階ごと・5階ごと・ボス直前に保証。通常勝利で生存者MP＋3、ボス勝利で＋8、レベルアップで守りも＋1。敵HPとボス攻撃を調整しました。
操作案内は実際の移動、探索会話、行動実行、連携予約で進みます。会話と戦闘を経験すると、ガルド＋リナの基礎連携を試せます。後の専用イベントでは選択により、威力・回復を伸ばす個人の約束、守り・効率・支援を伸ばす五人の約束へ分岐します。記録帳の遊び方から案内を終了・再表示できます。
攻撃・回復・被弾・毒・MP変化を短い光、斬撃、揺れ、浮かぶ数字、効果音で表示。演出中は次の入力を止め、連打による二重実行を防ぎます。効果音はコードで生成した音です。
10章のダンジョンは別の色調・床意匠を持ち、森の葉、氷の水面、機関の管、記憶の刻印などを表示します。
ボスは準備→固有攻撃→隙の周期。10階は全体大技、20階は弱った仲間を狙う、30階は物理を減らす盾、40階は毒、50階はMP吸収、60階は魔法で阻止できる回復、70階は防御で回避する攻撃低下、80階は魔法反射、90階は護衛召喚、100階は残りHPに応じた大技強化があります。予告を見て攻撃・防御・魔法・道具を選びます。

## 追加検証

### 敵の役割・装備の特殊効果

ウィッチは3ターン周期の1・3ターン目に、HP75%未満の生存敵を回復（対象がなければ術攻撃）。ナイトは1ターン目に盾を構えて物理攻撃を45%軽減。ゴーレム・オーク・ドラゴンは1ターン目に溜め、2ターン目に攻撃1.4倍。グールは2ターン目に毒を与えます。溜め攻撃・毒は防御で対処でき、盾には魔法が有効です。通常敵も画面上に行動を予告します。

装備タブで、装着した各装備に特殊効果を1つ選べます。変更は戦闘外・無料。装備を外すと効果も無効です。効果の選択は仲間ごとに保存します。別アイテムとしての在庫や付与費用は設けていません。

| 装備 | 効果 | 内容 |
| --- | --- | --- |
| 武器 | 破甲 / 吸魔 | 通常攻撃で敵の守りを半分・盾軽減を弱める / 通常攻撃で撃破するとMP＋3 |
| 防具 | 毒耐性 / 術耐性 | 毒を防具Lv分短縮 / 敵の術攻撃を20%軽減 |
| 魔導具 | 回復強化 / 先手節約 | 回復魔法＋20% / 初ターンのみ魔法MP−2、最低1 |

### 章の雰囲気・会話・冒険の成果

10枚の新規背景を章ごとに切り替え、森・氷水路・機関などの環境音も切り替えます。環境音はUnity内で合成したループ音です。Pで音楽・効果音・環境音を個別調整できます。

Pの文字速度は一括・ゆっくり・標準・速いの4段階。会話中はSpaceまたは「全文を表示」で即時表示でき、文章が出揃うと選択肢が現れます。Jの会話履歴には本文・話者・階層・選択した返答と探索中の状況会話を保存。最新1000件を20件ずつ表示します。物語の記録タブでは章の要約も読めます。

Jの冒険の成果では結末、4人との約束、守護者・戦闘・行動ターン・宝箱・道具・連携・獲得金貨・記憶・救助を確認できます。クリア画面にも記録へのボタンを設けました。古いセーブの会話履歴と戦闘・宝箱などの新しい累計は追加後から記録し、記録開始階を表示します。約束・記憶・救助は保存済みのフラグも反映します。設定は次の起動に引き継ぎます。

### 検証の実行

開発ビルドは `TowerAdventure.exe -full-playthrough "出力フォルダーの絶対パス"` で実行版100階検証を開始できます。移動・衝突・距離エンカウント・戦闘予約・会話選択・補給・購入・装備・階段の処理を実際のプレイヤーで動かし、各章・ボス・履歴・成果を撮影。通常版にはこの開発用操作を含めません。既存セーブを上書きせず、検証フォルダーに50階のチェックポイントとクリア記録を保存します。既知の経路を使い、移動を加速し演出を簡略化する自動操作なので、手動の迷路探索時間・音の聴感・長時間の操作感の評価とは区別します。

`ExpansionChecks.cs` は装備移動と重複防止、金貨・入荷条件、蘇生と不要な消費の防止、道具の予約・保存、旧セーブ移行、手動3枠と自動保存バックアップ、ボス固有行動、100階の自動進行を検証します。
100階の結果は `Checks/balance-100floors.csv` に出力。固定シードと定めた戦闘方針での進行確認で、全ての選択・経路の難易度を保証するものではありません。
開発ビルドの実行画面では最初の10階をスクリプトで歩き、会話・戦闘・連携・補給・装備購入・10階ボス撃破を確認します。結果は `VisualChecks/opening-playthrough.txt`、追加画面は `13-shop.png` ～ `21-opening-cleared.png` に記録します。手動での長時間プレイによる感触の調整は引き続き必要です。
